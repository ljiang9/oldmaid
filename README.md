# oldmaid 抽鬼牌

终端版 Old Maid 纸牌游戏：你 vs 电脑。纯标准库，零依赖。

## 玩法

- 52 张牌去掉一张 Q（黑桃 Q），剩余 **51 张**（含 3 张 Q）。
- 开局双方各拿一半，先丢掉手中所有对子。
- 轮流从对方手中抽一张牌，凑成对子立即丢掉；你从电脑手中按位置选牌，电脑从你手中随机抽。
- 三张 Q 中必有一张落单——最后手里剩这张 Q（鬼牌）的人输。

```bash
python -m oldmaid              # 交互对战
python -m oldmaid --auto 200   # 自动模拟 200 局并统计
python -m oldmaid --seed 42    # 固定发牌种子（可复现）
```

交互中输入 `1-N` 从电脑手中抽第 N 张牌，`q` 退出。

## 设计取舍

- **鬼牌是落单的那张 Q，不是预先指定的**：3 张 Q 中两张会配对丢掉，剩下一张注定落单。终局时牌堆必剩 exactly 1 张牌且必为 Q（其余点数都是 4 张，能配对干净），持有者判负。
- 电脑抽牌用 `secrets.SystemRandom`（交互）/种子随机（`--auto`），无作弊、无记牌，就是纯随机。
- 非 tty 下直接跑交互会中文报错并 exit 2，建议用 `--auto`。

## 已知局限

- 只有"你 vs 电脑"双人模式，无多人对战、无存档、无排行榜。
- 交互是行输入模式，每步需回车；不支持鼠标点选。
- 电脑是纯随机抽牌，没有难度等级——想赢主要靠运气（实测 `--auto` 200 局你赢约一半）。
